### `Python` `Pandas` `Scikit-learn` `Machine Learning`

Analyzed **180K+ order records** to understand late-delivery patterns and quantify their impact on business profitability.

**Key Results**

| Metric                  |           Result |
| ----------------------- | ---------------: |
| Orders Analyzed         |        **180K+** |
| Late Shipments          |        **54.7%** |
| Profit Loss Identified  |        **$2.1M** |
| Share of Total Profit   | **28% of $7.5M** |
| At-Risk Order Precision |          **77%** |

### 🔍 What I Did

* Cleaned and prepared large-scale order data
* Performed exploratory data analysis
* Identified high-risk regions and shipping modes
* Performed feature engineering
* Applied SMOTE for class balancing
* Built a Random Forest classifier
* Translated model results into business insights

**Business Impact:**
Identified the financial impact of delayed shipments and developed a predictive approach to help flag potentially at-risk orders.
