# 📂 Selected Work

## 01 — Supply Chain Late-Delivery Risk Analysis

**Python • Pandas • Scikit-learn**

This project looks at late shipments from a supply-chain perspective, with the goal of understanding where delivery problems occur and how much they can affect profitability.

### Results

* Analyzed **180K+ orders**
* Found that **54.7%** of orders were shipped late
* Identified concentration of late shipments across particular regions and shipping modes
* Estimated **$2.1M in profit loss** associated with delayed shipments
* Built a Random Forest classifier for identifying at-risk orders
* Used **SMOTE** to address class imbalance
* Achieved **77% precision** for at-risk order identification

### What this project demonstrates

`Large Dataset Analysis` `EDA` `Feature Engineering`
`Class Imbalance` `Machine Learning` `Business Impact Analysis`

# 🔬 How I Approach an Analytics Problem

I don't start with a dashboard.

I start with the **question**.

```text
Business Question
       │
       ▼
Understand the Data
       │
       ▼
Clean & Validate
       │
       ▼
Explore Patterns
       │
       ▼
Analyze with Python / SQL
       │
       ▼
Visualize Important Findings
       │
       ▼
Interpret the Results
       │
       ▼
Communicate the Business Impact
```

This approach helps keep the analysis focused on **why the result matters**, rather than only producing charts.
